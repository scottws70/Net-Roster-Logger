To Install:
Click "Releases" on the right.
Download your preferred package.
Install (Or Run, in the case of the AppImage)
Go to Settings, set up your preferences and populate/import your roster.

The Windows version will warn you that it's dangerous to install this. That's because it's unsigned. In order to make it signed and trusted, I would have to pay Microsoft. That's not something I do.
When you see the pop up that tells you it blocked from installing and warning you, click More Info, then Run Anyway and it will install and work just fine.
